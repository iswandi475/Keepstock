KEEPSTOCK PWA

File ini adalah launcher PWA dengan icon KEEPSTOCK.
Target web app:
https://script.google.com/macros/s/AKfycbwWjgy0gBgx8SMvXwlWe_aIbDw_WG4PAFmv_Le9WV3MnV6uyktmRD5W3iz97zcQxdhETg/exec

PENTING:
PWA harus di-host pada HTTPS/domain sendiri (misalnya GitHub Pages).
Google Apps Script sendiri tidak menyediakan manifest PWA dengan icon custom pada dialog shortcut.

Setelah folder ini di-host:
1. Buka alamat hostingnya di Chrome Android.
2. Pilih "Instal aplikasi" / "Tambahkan ke layar utama".
3. Icon KEEPSTOCK akan berasal dari icon-192/icon-512, bukan icon G Google Apps Script.
